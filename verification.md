# Verification
Run `powershell -ExecutionPolicy Bypass -File scripts\verify.ps1`. It builds Release, runs motion/button/settings/UI-state self-tests, executes offline bootstrap tests and local prerequisite scan, and renders disconnected/simulated-connected windows. Expected VERIFY OK. Raw build/self-test/setup logs: .verify/. State test preferences and logs: bin/Release/net8.0-windows/.verify/settings-test/. Native fatal errors in verification modes: bin/Release/net8.0-windows/.verify/runtime.log.

Coverage: dead zone/direction/diagonal cap/curve; L3/R3 flags/no repeated downs/rejected downs/failed release retention/retry/partial failure; persistence/reset/normalization/corrupt settings/autosave; keyboard slider limits and label hit-test; disconnected disabled Start, connect without autostart, disconnect stop and reconnect gate; official metadata selection plus rejection of HTTP/untrusted download hosts. Tests never download or install a runtime.

Setup UI: `powershell -STA -ExecutionPolicy Bypass -File Setup.ps1 -PreviewMissing -PreviewPath <absolute-png>`. Next in preview does not install/launch. Native UI render: `dotnet bin/Release/net8.0-windows/StickMouse.dll --preview <absolute-png>`. Add --connected-preview only for simulated state. Current screenshots reviewed at launch DPI; these are rendered native UI, not physical-controller evidence.

Manual release gates: test real XInput controller insertion/removal, L3 hold/drag and R3, disconnect during each hold, reconnect with sticks held, F8 and Start/Stop; slider dragging/keyboard/autosave after restart; multiple monitor DPIs and small window scroll. Setup: missing runtime and unchecked checkbox, no-network/timeouts, metadata/hash/signature rejection, denied UAC/cancelled installer, successful install and rediscovery, installed/offline launch. Run installation tests in a disposable clean Windows VM. No physical controller or clean install VM was available for these gates. Computer-use tooling did not expose the shell-launched windows on its desktop, so GUI automation was unavailable; render inspection and state/event tests were used instead.

Sources: native UI, build/raw process errors, isolated settings logs and local prerequisite results. Production runtime.log: SM001 input rejection, SM002 load fallback, SM003 save failure; UTC/code/exception type, rotated 256 KiB plus one backup. setup.log: setup failures and messages; SM104-SM112. SM900 fatal errors retain local stack. Capture matching UI message, timestamp, log and reproduction action. No secrets, controller payloads or telemetry. System-protected input remains outside app control. Update gates when mappings, native calls, settings, installation sources or packaging change.

OTA gates: self-tests verify RSA signature and tamper/downgrade/foreign URL/hash rejection, allowlisted archive extraction, injected-third-write rollback, successful replacement and unrelated data preservation. UI tests simulate offline, timeout, bad signature, malformed feed and I/O failure while controller mode is active; Start state, active state and update retry remain usable.
