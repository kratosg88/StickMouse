# Verification
Run `powershell -ExecutionPolicy Bypass -File scripts\verify.ps1`. It builds Release, runs motion/button/settings/UI-state self-tests, executes offline bootstrap tests and local prerequisite scan, and renders disconnected/simulated-connected windows. Expected VERIFY OK. Raw build/self-test/setup logs: .verify/. State test preferences and logs: bin/Release/net8.0-windows/.verify/settings-test/. Native fatal errors in verification modes: bin/Release/net8.0-windows/.verify/runtime.log.

Coverage: dead zone/direction/diagonal cap/curve; L3/R3 flags/no repeated downs/rejected downs/failed release retention/retry/partial failure; persistence/reset/normalization/corrupt settings/autosave; keyboard slider limits and label hit-test; disconnected disabled Start, connect without autostart, disconnect stop and reconnect gate; official metadata selection plus rejection of HTTP/untrusted download hosts. Tests never download or install a runtime.

Current screenshots reviewed at launch DPI; these are rendered native UI, not physical-controller evidence.

Manual release gates: test real XInput controller insertion/removal, L3 hold/drag and R3, disconnect during each hold, reconnect with sticks held, F8 and Start/Stop; slider dragging/keyboard/autosave after restart; multiple monitor DPIs and small window scroll. Run installation tests in a disposable clean Windows VM. No physical controller or clean install VM was available for these gates.
