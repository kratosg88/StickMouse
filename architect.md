# Architecture
.NET 8 Windows Forms, no third-party packages. Program.cs polls up to four XInput slots (idle 250ms, connected requested 8ms), requires explicit Start on hotplug and dispatches MouseEvent values through SendInput. Bindings.cs defines 16 standard controls, actions and stick roles; Interface.cs persists bounded preferences atomically after 450ms debounce. Legacy settings gain defaults, unknown keys are discarded and invalid enum values normalize safely.

ControllerMouse.cs owns neutral arming, trigger hysteresis, action edges, continuous cursor/scroll, precision and drag toggle. MouseButtonLatch.cs tracks accepted transitions for all five Windows mouse buttons. Shared actions aggregate owners; no duplicate downs or premature ups. Double-clicks never release a concurrently held button. Rejected input pauses control; rejected releases remain pending and retry while paused/disconnected. No forced-process/protected-desktop release guarantee. No real input injection runs in previews/tests.

MappingWindow.cs edits a deep copy: Apply commits and queues persistence, Cancel discards, Reset mappings preserves cursor preferences. Opening blocks Start/F8/tray activation until the dialog closes; input stays paused. Controls.cs renders the native charcoal/mint main UI and current mapping reference. The editor has native keyboard-accessible dropdowns, scrollable rows and a fixed action footer. GamepadIcons.cs supplies branding.

Setup.ps1 is a Windows PowerShell/WPF bootstrap: local Windows/runtime/files checks, explicit missing-runtime selection, official Microsoft metadata and SHA-512/Authenticode verification before UAC installation. Launch.cmd opens setup and starts the tray. The owned gamepad desktop shortcut invokes -QuickLaunch to check requirements then open/restore UI; known-folder lookup respects Desktop redirection. Direct/OTA app startup repairs the shortcut asynchronously; SM115 never blocks control. Keep the portable root in place. No login autostart, service or driver changes.

Tray.cs owns NotifyIcon/menu/lifetime. Normal launch registers the icon before hiding; Open/desktop launch restores the same instance through AppStartup.cs managed restore message. Close/minimize hides; explicit Quit/update/shutdown exits and releases input. Setup waits up to 12 seconds for a nonce-specific visible/tray-ready acknowledgement. Smoke tests use isolated mutex/caption/data and disable actual desktop integration.

OTA: UpdateProtocol.cs verifies pinned RSA-SHA256 envelopes, newer versions, exact GitHub repo URLs, bounded ZIP/hash/allowlisted paths and backup restoration on caught replacement errors. Updater.cs checks asynchronously at launch/every six hours; offline or failed checks never gate use. Explicit download/restart hands off to a trusted helper. Six-file package and signing identity remain compatible with v1.1.0+. Settings are outside the app tree. Crash/power-loss recovery and startup compatibility rollback are not implemented; backups are retained.

Publisher: CoderKnight assembly/setup metadata. Release signing key is DPAPI-protected outside source; public RSA trust is embedded. OTA signatures are separate from optional Windows Authenticode. No public certificate/trust installation or paid services. Native dispatch follows Microsoft's MOUSEINPUT and XINPUT_GAMEPAD contracts.
